# spec/

Spec files live here as `ADR-NNNNN-<shorttitle>.md`, one self-contained
file per spec: YAML frontmatter (`spec_id`, `status`, `rice`), `## Tasks`
(checkbox bullets, `**T<n> — <label> (<pts> pts):** <description>`),
`## Acceptance Criteria`, and `## BDD Scenarios` referencing
`bdd/bdd<NNNN>/*.feature` tagged `@ADR-NNNNN-T<n>` / `@ADR-NNNNN-AC<n>`.
